# Feature Graphic Template - Öne Çıkan Grafik Şablonu

## 📐 Boyutlar
- **Genişlik**: 1024 piksel
- **Yükseklik**: 500 piksel
- **Aspect Ratio**: 2.048:1
- **Format**: PNG veya JPEG (24-bit, alpha kanalı yok)
- **Maksimum Dosya Boyutu**: 1 MB

### Katmanlar (Layers)

1. **Arka Plan (Background)**
   - Oyunun ana renklerini kullanın (gradient önerilir)
   - Örnek: Koyu mavi → Mor gradient
   - Veya: Oyun ekranından bulanık bir screenshot

2. **Logo/İkon (Center)**
   - Oyun logosunu veya ana ikonu merkeze yerleştirin
   - Boyut: ~300x300 px
   - Kontrast için gölge ekleyin

3. **Ana Başlık (Main Title)**
   - "FluxGrid" veya oyun adı
   - Font boyutu: 60-80pt
   - Font: Bold, sans-serif
   - Renk: Beyaz veya açık renk (yüksek kontrast)

4. **Alt Başlık (Subtitle)**
   - "Sonsuz Puzzle Mücadelesi"
   - Font boyutu: 32-40pt
   - Font: Regular veya Medium
   - Renk: Beyaz veya açık gri

5. **Özellikler (Features)**
   - "Yeteneklerini Geliştir • Rekorları Kır"
   - Font boyutu: 24-32pt
   - Font: Regular
   - Renk: Açık gri veya beyaz

## 🛠️ Oluşturma Adımları

### Figma ile:

1. Yeni dosya oluştur: 1024 x 500 px
2. Arka plan gradient ekle
3. Oyun logosunu/ikonunu içe aktar ve merkeze yerleştir
4. Metin katmanları ekle (başlık, alt başlık, özellikler)
5. Gölge ve efektler ekle (drop shadow, glow)
6. Export: PNG, 1024x500, 2x quality

### Canva ile:

1. "Custom dimensions" seç: 1024 x 500 px
2. Şablon ara: "Game Banner" veya "App Banner"
3. Arka plan rengini/gradient'i ayarla
4. Logo ve metinleri ekle
5. Download: PNG format

### GIMP ile:

1. File > New: 1024 x 500 px
2. Arka plan katmanı oluştur (gradient tool kullan)
3. Logo/ikon ekle: File > Open as Layers
4. Metin ekle: Text tool (T)
5. Efektler ekle: Filters > Light and Shadow > Drop Shadow
6. Export: File > Export As > PNG

## ✅ Kontrol Listesi

Yayınlamadan önce kontrol edin:

- [ ] Boyut tam olarak 1024 x 500 piksel
- [ ] Dosya boyutu 1 MB'ın altında
- [ ] Format PNG veya JPEG (24-bit)
- [ ] Metin okunabilir (minimum 40pt font)
- [ ] Yüksek kontrast (metin arka plandan ayrılıyor)
- [ ] Logo/ikon net ve merkezi
- [ ] Güvenli alan içinde (kenarlardan 40px içeride)
- [ ] Yanıltıcı içerik yok (gerçek oyunu yansıtıyor)
- [ ] Telif hakkı ihlali yok
